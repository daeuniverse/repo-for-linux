# doona 文件 {#title-doona-文件}

doona 透過原生 API 管理 honk、查看流量。本文件適用於 v0.1.0-rc.5。


## 選擇版本 {#choose-edition}

| 版本 | 用途 | 下一步 |
| --- | --- | --- |
| 標準版 | 編輯組態、觀測流量、診斷路由 | 依[快速入門](quick-start.md)使用內嵌的 doona，或[安裝獨立套件](install.md#doona)；然後[首次登入](first-sign-in.md) |
| doona lite | 用較精簡的介面完成組態任務，目前為測試中的預覽版 | [安裝 lite](lite.md#lite-install)，然後[連線至後端](lite-connect.md) |

版本差異見[版本比較](editions.md)。若要用範例資料體驗介面，開啟[標準版示範](https://demo.daeuniverse.org/)或 [lite 示範](https://demo.daeuniverse.org/lite/)。

| 你目前的情況 | 閱讀頁面 |

## 查找需求或排查問題 {#查找需求或排查問題}

- 頁面或操作無法使用：[功能需求](feature-requirements.md)。
- 查找組態欄位：[組態參考](configuration.md)。
- 確認修改儲存在哪裡、是否需要重新啟動：[doona 能修改什麼](what-doona-can-change.md)。
- 連線、登入或寫入失敗：[疑難排解](troubleshooting.md)。
- 建置或參與開發：[開發](development.md)。

引擎問題請提交至 [honk issues](https://github.com/daeuniverse/honk/issues)。
