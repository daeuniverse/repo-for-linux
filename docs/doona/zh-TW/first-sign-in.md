# 首次登入 {#title-首次登入}

將標準版連接到已啟動的 honk，視需要建立管理員，並檢查後端狀態。先完成[服務管理](service-management.md)中的啟動步驟；lite 使用者請閱讀[連線至 doona lite](lite-connect.md)。

## 1. 開啟介面 {#1-開啟介面}

在閘道器或區域網路裝置上開啟 `http://192.168.1.1:9527/ui/`，將位址替換為閘道器的 API 監聽位址。使用主機名稱或獨立託管的介面時，先設定[主機名稱與來源存取](install.md#other-origin)。

首次使用且未儲存後端連線設定檔時，介面會在託管位址探索 API。如果表單指向錯誤的後端，選取**變更後端網址**。找不到 API 或無法使用驗證功能時，查看[登入需求](feature-requirements.md#req-sign-in)。

登入前，可用右上角的控制項切換語言、配色和明暗模式。

## 2. 按目前的表單登入 {#2-按目前的表單登入}

| 表單 | 操作 |
| --- | --- |
| **建立管理員** | 輸入**使用者名稱**、**密碼**和**確認密碼**，選取**建立並登入**。 |
| **登入** | 輸入既有管理員的**使用者名稱**與**密碼**，選取**登入**。 |
| **需要 Token** | 在 **Token** 中輸入後端設定的密鑰，選取**連線**。 |

建立帳號時，使用者名稱須為 1 至 64 個 ASCII 英文字母、數字、底線、句點或連字號。密碼須為 8 至 128 個字元，且兩次輸入必須相同。

使用 Token 登入時，可透過 **Token** 欄位的顯示／隱藏控制項，在連線前核對輸入的密鑰。

![建立管理員](/doona/screenshots/zh-TW/login-setup.webp)

## 3. 檢查後端 {#3-檢查後端}

1. 開啟**系統狀態**。在手機上，先選取底列的**活動**。
2. 查看生命週期狀態和**引擎**卡片，確認引擎為 honk，版本與安裝的建置一致。
3. 查看**後端能力**，透過[功能需求](feature-requirements.md)判斷操作無法使用的原因。

繼續閱讀[路由你的第一條連線](tutorial.md)，新增訂閱並驗證代理路由；查找頁面可用[介面導覽](tour.md)。

## 登入失敗時 {#登入失敗時}

| 現象 | 下一步 |
| --- | --- |
| 瀏覽器無法開啟頁面 | 在閘道器執行 `curl http://192.168.1.1:9527/api`，替換範例 IP。如果閘道器本機可達，但區域網路瀏覽器無法連線，檢查閘道器防火牆是否阻止存取 9527 連接埠。如果本機也失敗，按[服務管理](service-management.md)檢查服務與監聽位址。 |
| 表單提示沒有原生 API | 查看 [honk 版本](requirements.md#honk-version)。 |
| 管理員建立請求遭拒 | 核對[登入需求](feature-requirements.md#req-sign-in)中的用戶端位址條件。 |
| 憑證遭拒或忘記密碼 | 按[登入疑難排解](troubleshooting.md#sign-in)處理。 |

身分驗證欄位見[組態參考](configuration.md)。不要在螢幕擷取畫面或問題報告中包含密碼或 Token。
