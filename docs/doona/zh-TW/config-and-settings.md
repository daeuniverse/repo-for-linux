# 修改組態與設定 {#config-and-settings}

在 doona 標準版中編輯設定檔或修改設定。設定鍵及範例見[組態參考](configuration.md#config)；儲存位置與生效方式見 [doona 能修改什麼](what-doona-can-change.md)。


## 選擇組態編輯器 {#config-page}

在設定分區開啟**組態**。控制項無法使用時，先檢查[編輯條件](feature-requirements.md#req-config-edit)。

| 分頁 | 用途 |
| --- | --- |
| **模組** | 尋找組態區段，透過**開啟頁面**進入對應編輯器。 |
| **全域設定** | 透過表單修改提供的全域欄位。 |
| **設定檔** | 查看或編輯完整的來源檔案，檢查診斷結果。 |
| **備份與修訂** | 匯出組態、匯入伺服器檔案或復原已儲存的修訂。參閱[使用條件](feature-requirements.md#req-revisions)。 |

**組態版本**識別已接受的設定，旁邊的狀態顯示診斷摘要。**後端已遮蔽監聽密鑰的值**表示回傳文字隱藏了這些值。

預設開啟**模組**；透過來源連結進入或缺少主檔案本文時，開啟**設定檔**。只有 doona 支援其設定的引擎才會顯示**全域設定**。

**內容不完整**表示來源文字不完整，或其 SHA-256 與後端回報的值不符，不一定是密鑰遭遮蔽所致。這類來源無法在 doona 中編輯，請在主機上修改檔案。

訂閱在[節點](routing.md#nodes)中管理，群組成員在[策略](routing.md#policies)中修改，路由範本和單條規則在[規則](routing.md#rules)中編輯。


## 編輯設定檔 {#edit-source}

1. 開啟**設定檔**分頁，從**設定檔**選擇器中選取檔案。
2. 編輯前檢查檔案標記。如果唯讀，參閱[來源權限與拒絕原因](troubleshooting.md#read-only)。
3. 修改文字。**未套用**表示草稿尚未儲存；**取消**會捨棄草稿。
4. 如果提供**驗證**，點選後檢查診斷結果。用**前往**定位行，或用**開啟**檢查其他檔案。參閱[驗證條件](feature-requirements.md#req-validation)。
5. 點選**套用**並等待結果。成功通知會顯示已寫入的檔案，並確認組態已重新載入。操作失敗或結果未確認時，先閱讀通知，再決定是否傳送下一次變更。

重新整理或關閉頁面會遺失未套用的草稿。診斷結果會區分已接受的組態和目前草稿；支援驗證時，輸入修改會觸發新的草稿檢查。

檔案選擇器區分 **主組態**、**引入檔**、**訂閱** 和 **引擎產生** 來源。懸停在行數和大小上可檢視載入時間。訂閱更新會取代訂閱來源，引擎會覆寫產生的來源，因此應修改產生它們的設定。在唯讀來源中輸入時，每個檔案會提示一次。

已接受設定的診斷會保留到草稿完成驗證。套用變更或收到新設定世代後，之前的驗證結果會清除。清空等級篩選會回到 **全部**。舊驗證連結會開啟 **設定檔** 中的診斷。

如果編輯期間檔案發生變更，儲存會暫停。檢查該變更後，選擇**保留修改**，再點選**套用**，即可用草稿取代較新的檔案；選擇**取消**則捨棄草稿，使用較新的文字。

需要重新啟動的通知表示此次編輯已遭拒。請按[只能透過重新啟動生效的設定](what-doona-can-change.md#restart-global)處理，不要反覆點選套用。

### 建立引入檔案 {#建立引入檔案}

1. 在**設定檔**中點選**新增檔案**。
2. 若對話框提供目錄和副檔名，只需填寫 **名稱**。有多個 **路徑樣式** 時先選擇一個。否則，在 **路徑** 中填寫相對於主設定所在目錄的 `.dae` 路徑。
3. 如果提示路徑不符合任何已載入的引入樣式，先修正路徑。
4. 點選**建立**。空檔案會在編輯器中開啟，隨後按上述步驟編輯。

### 使用全域設定表單 {#使用全域設定表單}

1. 開啟**全域設定**，從**設定檔**選擇器中選擇要編輯的區段。
2. 按欄位標示的單位和範圍修改值。設定鍵的含義見[組態參考](configuration.md#config)；重複項目須在**設定檔**中處理。
3. 點選**寫入並重新載入**，或用**放棄修改**捨棄草稿。離開前檢查操作結果。

若寫入成功但無法讀回新設定，草稿會保留，並提供 **重試**。

選擇器包含主檔案及 include 檔案中的全域區段；沒有全域區段的主檔案可新增一個。**未設定** 使用引擎預設值。清空數值欄位會將其設為未設定；整數欄位不接受小數點，連接埠數字不分組，例如 `8080`。

訂閱本文存入狀態資料庫的 `subscription_body` 表，資料庫位置見[設定參考](configuration.md#config)。獨立 `.sub` 檔案屬於舊儲存格式，啟動遷移說明見 [honk 訂閱參考](https://github.com/daeuniverse/honk/blob/main/doc/zh/reference/subscription.md#拉取持久化与恢复)。

### 匯出或復原組態 {#匯出或復原組態}

開啟**備份與修訂**，選擇所需操作：

| 任務 | 操作 |
| --- | --- |
| 下載已接受的組態 | 點選**匯出組態**。分享下載檔案前，檢查其中的憑證。 |
| 用伺服器檔案取代資料庫組態 | 點選**匯入伺服器檔案**，檢查提示後確認。這會讀取 honk 啟動時使用的檔案樹，不會上傳本機檔案。 |
| 復原已記錄的修訂 | 開啟修訂，檢查中繼資料和來源，再點選**復原修訂**並確認。 |
| 檢查結果未確認的匯入或復原 | 使用**重新整理**檢查已接受的操作，再決定是否發起另一次寫入。 |

復原修訂前，核對各來源的 SHA-256 值。匯入或復原期間，若資料庫目前修訂發生變化，需重新核對並確認取代。

只需下載選取的來源文字時，在**設定檔**中使用**下載來源檔案**；分享前同樣須檢查內容。可用操作和匯出限制見[備份與修訂條件](feature-requirements.md#req-revisions)。


## 開啟設定 {#settings-page}

**設定**分為**一般**和**外觀**兩個分頁。一般包含後端連線設定檔、暫時執行期覆寫、地理資料、延遲探測和關於。沒有連接後端時也能開啟此頁。

### 連接或切換後端 {#連接或切換後端}

1. 在**一般** → **後端**中選擇**連線設定檔**，或點選**新增連線設定檔**。
2. 在**後端網址**填寫後端根位址或反向代理前綴，不要附加 `/api/v1`。使用示範資料時填寫 `mock`；空位址無法儲存。
3. 使用 Token 驗證時填寫 **Token**。使用密碼驗證時，按[登入指南](first-sign-in.md)操作。
4. 點選**測試連線**，檢查結果。
5. 點選**儲存**，介面會儲存連線設定檔並重新載入頁面。

切換連線設定檔或確認其對話框會捨棄未儲存的網址和 Token 修改。**重新命名連線設定檔**和**刪除連線設定檔**用於管理已儲存的項目。**登出**會結束密碼登入工作階段，或刪除本瀏覽器儲存的 Token；刪除 Token 不會使其在後端失效。

選擇其他連線設定檔會儲存選擇並立即重新載入頁面。確認 **新增連線設定檔**、**重新命名連線設定檔** 或 **刪除連線設定檔** 後也會重新載入；新連線設定檔使用示範資料。

配對連結會填入 **後端網址** 和 **Token**，點 **儲存** 後生效。儲存只修改此瀏覽器的連線設定檔，不修改 honk 設定。測試或登入失敗時，見[登入疑難排解](troubleshooting.md#sign-in)。


### 修改暫時執行期選項 {#runtime-options}

先檢查[執行期覆寫條件](feature-requirements.md#req-runtime-options)。

1. 開啟**暫時執行期覆寫**，檢查目前顯示的是**組態值**還是**執行期覆寫**。
2. 修改提供的日誌等級、記錄數量、流量紀錄保留時間或記錄模式。
3. 點選**套用**，或用**放棄修改**捨棄草稿。查看各項旁的記錄狀態。

編輯期間若後端執行期選項發生變化，doona 會保留草稿並提示變化。

可用欄位包括 **日誌等級**、**日誌保留筆數**、**DNS 記錄保留筆數**、**流程保留筆數** 和 **流程保留秒數**。**流程記錄** 提供 **依流程需求**，**日誌記錄** 提供 **依日誌需求**，**DNS 記錄** 提供 **依 DNS 日誌需求**；三者也都提供 **常開** 和 **關閉**。記錄器狀態顯示為 **記錄中**、**未記錄** 或 **組態禁止**。

覆寫值的有效期見[執行期變更](what-doona-can-change.md#change-runtime)。需要永久儲存時，使用**在組態中編輯持久設定**，並查閱[組態參考](configuration.md#config)。


### 更新地理資料或修改來源 {#geodata}

按所需操作檢查[檔案可用條件](feature-requirements.md#req-geodata)、[更新條件](feature-requirements.md#req-geodata-update)和[設定條件](feature-requirements.md#req-geodata-settings)。

1. 開啟**地理資料**並檢查檔案。展開**詳細資料**，查看檢查時間和下載資訊。
2. 要立即下載已設定的來源，點選**立即更新**並等待結果。
3. 要修改來源，在**來源**中選擇預設來源，或選擇**自訂**並填寫網址。檢查缺少分類的警告。在自訂對話框中，點選提供的**套用並更新**或**套用**。
4. 按需調整提供的**下載路由**、**SHA-256 驗證**或**自動更新**。選擇**指定群組**時，還須選擇群組才會儲存路由。這些控制項在修改後儲存，須檢查各次操作結果。
5. 要移除覆寫值，點選**重設為預設值**，閱讀確認提示後再繼續。

**來源** 提供 **Loyalsoldier**、**MetaCubeX 完整版**、**MetaCubeX 精簡版** 和 **自訂**。使用 honk 時，每個自訂 URL 清單最多接受四個位址，依序嘗試。點 **編輯** 可重新開啟自訂對話框。

**詳細資料** 顯示 **上次檢查**、**下次檢查**，以及各檔案的大小、下載主機和路由。檔案表格顯示各檔案的更新時間。

永久儲存方式見[地理資料的儲存與生效](what-doona-can-change.md#change-geodata)；下載或生效失敗時，參閱[地理資料疑難排解](troubleshooting.md#geodata-update)。

### 設定手動探測偏好 {#設定手動探測偏好}

1. 開啟**延遲探測**。
2. 選擇**探測方式**、**IP 版本**、**連線**和**策略群組探測**。
3. 返回節點或群組，使用測試按鈕。**以選項探測…**可以調整本次測試的選項。

**暖探測（重用連線）**重用連線；**冷探測（新連線）**建立新連線。**策略群組探測**可選**直接成員**或**含巢狀群組的所有節點**。

查看[探測需求](feature-requirements.md#req-probes)和[結果含義](routing.md#policies)。背景檢查使用 **在組態中編輯健康檢查**，欄位含義見[設定參考](configuration.md#config)。

### 修改外觀 {#appearance}

1. 開啟**外觀**。
2. 選擇**語言**、**配色**和**明暗模式**，按需調整**日期格式**、**時間格式**或**啟動時開啟**。
3. 使用 Glass 配色時，在**背景圖片**中點選**選擇圖片**，或用**使用預設**恢復內建背景。按需調整提供的遮罩和模糊控制項，使文字清晰可讀。

#### 日期與時間 {#日期與時間}

- **日期格式**預設使用**自動（瀏覽器地區）**，不受介面語言影響；也可選擇**日/月/年**、**月/日/年**或**年-月-日**。
- **時間格式**預設為 **24 小時制**。**12 小時制**使用介面語言的上午、下午字樣；**自動（瀏覽器地區）**遵循瀏覽器地區。

這些選擇適用於整個介面，包括圖表和日誌熱圖。

#### 版面配置與啟動頁面 {#版面配置與啟動頁面}

還可設定 **字標**、**通知位置** 和 **鏡像版面**。鏡像版面會左右翻轉介面。**顯示國旗** 控制節點名稱前的國旗，不改變路由。**活動卡片顯示趨勢圖** 控制流量、CPU 和延遲迷你圖。

**啟動時開啟** 預設為 **活動**，修改後立即儲存。它只在位址沒有頁面路由時生效，明確的頁面連結仍開啟原目標。未設定後端且位址沒有頁面路由時，會開啟 **設定**。

#### 玻璃配色與桌布 {#玻璃配色與桌布}

玻璃配色包括**液態玻璃**、**玻璃**、**毛玻璃**和**著色**：

- Firefox 和 Safari 將液態玻璃顯示為普通玻璃。液態玻璃支援範圍見[瀏覽器需求](feature-requirements.md#req-browser-settings)。
- 毛玻璃使用均勻模糊。著色表面接近不透明且不模糊。
- 液態玻璃的**事件**和**日誌**表格不使用折射和亮邊。
- 系統開啟減少透明度、增強對比度或強制色彩時，介面使用實色表面。

自訂桌布也顯示在登入頁，長邊最多縮放至 2560 像素。

| 控制項 | 預設值或限制 |
| --- | --- |
| **可讀性遮罩** | 預設開啟。 |
| **淡化** | 預設及最大值均為 60%；淺色模式使用白色，深色模式使用黑色。 |
| **模糊程度** | 液態玻璃、玻璃和毛玻璃的範圍為 0% 到 150%。低於 100% 時會增加表面填充。著色配色沒有模糊控制項。 |

瀏覽器支援和儲存條件見[瀏覽器設定](feature-requirements.md#req-browser-settings)。哪些選擇屬於目前瀏覽器，見[儲存位置說明](what-doona-can-change.md)。

#### 萬聖節配色 {#萬聖節配色}

**萬聖節**位於配色清單的**其他**之下。**白晝**以南瓜橘搭配羊皮紙底色，**午夜**以南瓜橘搭配深紫底色。執行中狀態顯示為**鬧鬼中**，無法使用與降級狀態顯示為**中邪**。卡片帶有淡淡的南瓜燈、蝙蝠、黑貓與蜘蛛網插圖，鴨子標誌戴上巫師帽。只有選用此配色時才會載入其樣式。

### 尋找說明和錯誤詳情 {#尋找說明和錯誤詳情}

在**關於**中，選擇**指南**開啟文件，或選擇**鍵盤快捷鍵**查看清單。**複製最近錯誤**可複製近期 API 錯誤，供提交錯誤報告；失敗通知中的**複製錯誤**則複製該次請求的詳情。

**關於 doona** 顯示引擎、API 和契約版本、授權條款及隱私聲明。支援時會提供 **安裝為應用程式**；尚未作為應用程式執行時，iOS/iPadOS 的 Safari 及 macOS 的 Safari 26 或更新版本會顯示手動安裝步驟。API 主版本不是 1 時會顯示警告。

JSON 讀取回傳空本文或沒有收到回應時，會重試一次再顯示錯誤。錯誤詳細資料包含請求及關鍵回應標頭。
