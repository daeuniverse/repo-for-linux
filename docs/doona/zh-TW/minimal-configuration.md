# 最小組態 {#title-最小組態}

依要使用的介面選擇組態。其他選項見[組態參考](configuration.md)。

| 介面 | 組態 |
| --- | --- |
| honk 內嵌的標準版 | [快速入門第 2 步](quick-start.md#2-設定-honk) |
| honk 內嵌的 doona lite | [安裝 doona lite](lite.md#lite-install) |
| 單獨安裝的介面檔案 | [單獨安裝 doona](install.md) |

這些區塊啟用介面與原生 API，不設定代理路由。請保留現有 honk 組態，或按[快速入門](quick-start.md)準備後端。
