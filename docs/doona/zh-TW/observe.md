# 觀測流量 {#observe}

在標準版中依下表選擇監控頁面，並確認資料涵蓋範圍。檢查步驟見[常見操作](common-tasks.md)；精簡版請參閱 [doona lite](lite.md)。

| 想了解什麼 | 查看哪裡 |
| --- | --- |
| 目前流量和引擎狀態 | [活動](#activity) |
| 後端版本、警告或缺少的功能 | [系統狀態](#overview) |
| 目前連線的路由 | [連線](#connections) |
| 已記錄的路由決策 | [分流](#flows) |
| DNS 回應、快取或解析歷史 | [DNS](#dns) |

## 活動 {#activity}

**活動**包含流量、連線、延遲和系統卡片。設定尚未完成時，**開始使用**提供剩餘任務的入口，可依[教學](tutorial.md)完成設定。

每一步在滿足對應條件時自動完成：

- 已有訂閱或代理節點。
- 已選擇路由方式。
- 某個群組選中的代理節點已有成功的延遲結果。

完成全部步驟或關閉卡片後，卡片會隱藏，目前瀏覽器會記住此狀態。

![活動儀表板](/doona/screenshots/zh-TW/activity-light.webp)

| 卡片或控制項 | 如何解讀 |
| --- | --- |
| **出站模式**和**全域出站** | 依[切換模式](common-tasks.md#global-mode)的步驟修改。 |
| **下載**和**上傳** | 開啟連線頁面的流量檢視。先閱讀統計範圍提示，再判斷數值是否代表閘道總量。 |
| **活動連線** | 開啟連線清單。 |
| **延遲** | 追蹤策略群組所選節點的延遲。 |
| **CPU 使用率** | 開啟系統狀態。 |
| 裝置和網域排行 | 統計後端回傳的連線樣本。 |
| 通知 | 合併相同通知，並顯示重複次數。 |

歷史資料或指標無法使用時，檢查[運作狀態條件](feature-requirements.md#req-runtime-status)及[歷史記錄條件](feature-requirements.md#req-traffic-history)。

按**延遲**可在節點頁面開啟對應節點。**自動**追蹤活動連線最多的策略群組；手動選擇會儲存在目前瀏覽器，且只影響這張卡片。

CPU 和延遲趨勢需要兩個樣本。延遲測試失敗會留下缺口，更改選擇會重新開始記錄該趨勢。運作狀態讀取失敗時，變淡的數值保留上一次成功讀取的結果。

通知角標統計合併後的不同通知數，不累計重複次數。**串流就緒**僅保留在事件頁面。不指向特定記錄、原因為 `recording_changed` 的流程缺口表示記錄歷史的邊界，不一定代表遺失了記錄。

啟動頁可在[外觀](config-and-settings.md#settings-page)中修改；其中的**活動卡片顯示趨勢圖**控制活動卡片的趨勢顯示。

透過**編輯儀表板**新增、移動、調整大小或移除卡片。**完成**儲存版面。如需放棄修改，按**取消**並確認。版面儲存受[瀏覽器條件](feature-requirements.md#req-browser-settings)限制。

每種元件最多放置三份。可選尺寸因元件而異，調整一張卡片不會改變相鄰卡片的大小。移除卡片後，只要編輯器仍開啟，就可使用**復原**。

元件庫提供**訂閱額度**、**出站失敗**、**節點可用性**和**DNS 延遲**。記憶體可顯示為圖表或帶數值的**迷你折線圖**卡片。寬圖表會在旁邊顯示峰值和平均值。儀表板與浮動面板共用的元件庫見[元件](features.md#widgets)。

![儀表板編輯器](/doona/screenshots/zh-TW/dashboard-settings.webp)


## 系統狀態 {#overview}

功能無法使用時，先在**系統狀態**檢查後端。

頁首顯示引擎狀態、**組態版本**、**運作時間**、**CPU 使用率**和**上次重載**。組態版本表示目前生效的組態修訂，不是 `generation` 編號。

| 區域 | 檢查內容 |
| --- | --- |
| **引擎** | 引擎版本、組建、API 和執行個體資訊。還顯示啟動時間、組態生效時間及**基本**或**完整可觀測**設定檔。 |
| **流量計數** | 計數起始時間和涵蓋範圍，以及上傳、下載和連線數量。TCP 與 UDP 分別計數，速率間隔表示測量週期。 |
| **記憶體** | 後端回報的行程與 cgroup 記憶體。cgroup 計量條將用量與非零上限比較；上限為零或未提供時，不顯示計量條。 |
| **資料路徑** | 核心掛載檢查及降級警告，包括狀態資料庫故障。檢查項目包含程式、hook、map 及掛載清單。 |
| **後端能力** | 後端宣告提供的功能。選擇一項可開啟對應頁面。 |
| **未開啟的功能** | 各項限制的原因、啟用所需的設定或啟動選項，以及使用條件連結。涵蓋規則與群組編輯、匯入與修訂歷程、地理資料設定等功能。僅在存在限制時顯示。 |

按**匯出狀態 JSON**可儲存後端回報的狀態。欄位或操作缺失時，檢查[狀態功能條件](feature-requirements.md#req-runtime-status)及[重載、暫停和恢復條件](feature-requirements.md#req-reload-suspend)。

狀態卡片載入時會用佔位內容保留空間。載入提示顯示進度指示，計量元件向輔助技術提供名稱和數值文字。

![系統狀態](/doona/screenshots/zh-TW/system-status-meters.webp)


## 連線 {#connections}

**連線**預設開啟**流量**。選擇**清單**可查看單條連線；指向具體連線或篩選清單的連結會直接開啟此分頁。

![流量檢視](/doona/screenshots/zh-TW/connections-traffic.webp)

按圖中的資料點或清單列可查看連線詳細資料。後端提供資訊時，詳細資料會顯示出站、鏈和命中規則。依[出站排查步驟](common-tasks.md#why-outbound)可開啟規則或執行追蹤。

![連線清單](/doona/screenshots/zh-TW/connections-list.webp)

篩選也會搜尋出站、鏈和規則。**匯出 CSV**匯出篩選後的清單。清單為空時，先閱讀截斷或可見範圍提示；[連線條件](feature-requirements.md#req-connections)說明了涵蓋範圍及哪些連線可以關閉。

連線沒有可用位址或網域時，該列的新增規則圖示無法使用。支援相應操作時，**更多操作**還提供**編輯命中規則的出站設定**、**檢視流程**、**僅顯示此裝置**和**關閉連線**。

僅依裝置和網路篩選時，**全部關閉**會關閉所有符合的活動連線，包括確認後新開的連線。如果還依出站、規則或文字篩選，或清單被截斷、超出批次操作上限，則只關閉列出的 ID。核心直連連線會被略過。


## 分流 {#flows}

**分流**在**總覽**和**記錄**中顯示已記錄的流程，需要[流程記錄功能](feature-requirements.md#req-flows)。

![分流圖](/doona/screenshots/zh-TW/routing.webp)

在**總覽**中選擇一條路徑，再按顯示流程數量的按鈕，開啟對應記錄。在**記錄**中選擇一列可查看路由追蹤；追蹤不完整時，先閱讀原因。關聯連線仍存在時，**檢視連線**可開啟該連線。

按**清除路徑篩選**可取消固定路徑。要從流程記錄建立規則，使用記錄列上的新增規則圖示；詳細資料面板中沒有此圖示。

**記錄設定**開啟記錄控制項，其範圍和有效期見[執行期修改](what-doona-can-change.md#change-runtime)。


## DNS {#dns}

可用分頁取決於後端的[查詢](feature-requirements.md#req-dns-query)、[快取](feature-requirements.md#req-dns-cache)和[記錄](feature-requirements.md#req-dns-log)能力。

![DNS 統計](/doona/screenshots/zh-TW/dns.webp)

| 分頁 | 資料與操作 |
| --- | --- |
| **統計** | 彙整最新一頁解析記錄和快取資訊。按排行中的網域可篩選記錄。 |
| **解析記錄** | 選擇一列查看已記錄的請求與回應。**匯出 CSV**僅匯出已載入的記錄，不包含完整歷史。 |
| **快取** | 依名稱和記錄類型篩選快取項目。**顯示已到期**包含已到期項目。刪除符合項目或清空快取前，先閱讀確認內容。 |
| **查詢** | 執行診斷查詢，步驟見[查詢網域](common-tasks.md#dns-resolution)。這些查詢不會出現在解析記錄中。 |

從**解析記錄**建立規則時，使用列上的新增規則圖示，為完整網域建立 DNS 請求規則。DNS 規則無法使用時，會改為開啟路由規則。選擇**網域後綴**可包含子網域。

快取支援完整網域、後綴、關鍵字和正規表示式篩選，並可同時限制記錄類型。關鍵字比對任意位置，例如 `cdn` 可比對 `cdn.example.com`；後綴 `cdn` 僅比對 `cdn` 和以 `.cdn` 結尾的網域。

後端不支援刪除時，仍可篩選。**清除篩選**會重設條件，並移除頁面 URL 中的網域篩選。

快取回報僅存於記憶體時，重新啟動會清空項目。刪除符合項目時，確認內容顯示符合數量；依名稱刪除時，顯示網域和記錄類型；**清除全部快取**無法復原。**沒有快取項目**表示快取為空，**沒有符合的快取項目**則表示目前篩選條件沒有符合項目。

![包含已到期項目的 DNS 快取](/doona/screenshots/zh-TW/dns-cache-expired.webp)


## 日誌 {#logs}

**日誌**顯示引擎日誌。收不到記錄時，先檢查[日誌記錄條件](feature-requirements.md#req-logs)。

![引擎日誌](/doona/screenshots/zh-TW/logs.webp)

用**等級**和**模組**篩選日誌串流。**暫停**暫停畫面更新，期間緩衝區僅保留頁面上限內的最新記錄。**清空**清空本頁記錄，**匯出**下載已接收的記錄，**複製記錄**以與**匯出**相同的格式複製單列記錄。

低於引擎記錄等級的選項會標為未記錄。要更改引擎等級，開啟**記錄設定**；選擇更低的顯示篩選等級無法找回未記錄的訊息。

缺口標記表示重新連線後有部分記錄無法重播。記錄開始前的啟動訊息須從[服務日誌](service-management.md)查看。


## 事件 {#events}

**事件**顯示後端事件，最新事件在前。事件串流無法使用時，檢查[事件條件](feature-requirements.md#req-events)。

**種類**初始為**排除運作狀態更新**。選擇**所有種類**或指定種類，再選擇一列查看詳細資料和相關連結。**匯出 JSON**匯出目前顯示的事件，**複製記錄**依匯出格式複製單個事件，不包含外層陣列。

清單顯示**時間**、**種類**和**摘要**。工具列顯示連線狀態、事件保留上限，以及可用時的**可從上次位置續傳**提示。組態可用時，**組態生效**提供**檢視組態**；**流程記錄遺失**可提供**檢視流程記錄**和**記錄設定**。

重新連線後，可重播仍保留的事件。缺口標記表示更早的事件已無法重播。
