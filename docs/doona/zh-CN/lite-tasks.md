# doona lite 常用任务 {#lite-tasks}

[连接 lite](lite-connect.md) 后，可导入节点和编辑 honk 配置。无法编辑时，检查[配置写入要求](feature-requirements.md#req-config-edit)、[完整校验要求](feature-requirements.md#req-validation)和 [lite 后端要求](editions.md#backend-requirements)。

## 应用草稿 {#应用草稿}

修改订阅、策略组、路由、DNS 或全局设置后，按以下步骤应用：

1. 选择**查看并应用**。
2. 核对待应用的修改，再选择**应用**。
3. 等待**配置已保存并应用。**通知，再次检查资源。如果通知报告失败或结果尚未确认，请先阅读详情再重试。

节点导入使用下文的直接应用流程。保存位置与生效规则见 [doona 能修改什么](what-doona-can-change.md)。


## 从分享链接导入节点 {#lite-task-import}

1. 打开**节点**，选择**添加节点**。
2. 选择**粘贴链接**，在**分享链接**中每行粘贴一个链接。
3. 核对识别出的节点，修正无效行。
4. 导入一个节点时，选择**添加**；多个节点则选择**添加 N 个节点**。此操作会立即写入并应用。随后检查节点是否出现在列表中。

无法导入时，查看[节点要求](feature-requirements.md#req-nodes)与[语法校验](feature-requirements.md#req-validation)。


## 添加订阅 {#lite-task-subscription}

1. 打开**订阅**，选择**添加订阅**。
2. 输入**订阅链接**；填写**名称（可选）**，或留空使用建议名称。
3. 选择**保存**。新增行仍是草稿。
4. 按本页的**应用草稿**操作，再检查订阅节点。

编辑和删除订阅也使用这一审阅流程。获取失败时，检查[订阅刷新要求](feature-requirements.md#req-subscription-refresh)。


## 创建策略组 {#lite-task-group}

1. 打开**策略组**，选择**创建组**。
2. 输入**名称**，在**策略**中选择**手动选择**，再选择**创建**。
3. 在**编辑组**中，从**可用节点和订阅**找到一个节点，选择其**添加**按钮。确认节点出现在**已加入**中。
4. 按本页的**应用草稿**操作，再检查组成员。

组操作的条件见[组编辑要求](feature-requirements.md#req-group-edit)。


## 添加域名规则 {#lite-task-rule}

1. 打开**路由**，选择**添加规则**。
2. 选择**域名及子域名**，在**值**中输入 `example.com`，按 Enter。
3. 在**走向**中选择目标组，设置**位置**，再选择**添加**。
4. 按本页的**应用草稿**操作，再检查域名规则是否出现。

**用模板重建规则**会替换草稿中的规则，应用前请审阅替换内容。无法编辑时，查看[规则要求](feature-requirements.md#req-rules)。


## 添加 DNS 服务器 {#lite-task-dns}

1. 打开 **DNS**，选择**添加 DNS 服务器**。
2. 在**服务商**中选择**自定义**，输入唯一的**名称**和**服务器地址**，例如 `tls://1.1.1.1:853`，再选择**添加**。
3. 打开该服务器的**操作**菜单，选择**设为默认**。
4. 按本页的**应用草稿**操作，检查服务器和默认规则。

配置字段见[配置参考](configuration.md)，写入条件见[规则要求](feature-requirements.md#req-rules)。


## 修改全局设置 {#lite-task-setting}

1. 打开**设置**，选择**嗅探**。
2. 将**嗅探超时**设为 `200`，**时长单位**设为 `ms`。
3. 按本页的**应用草稿**操作，再打开设置核对其值。

需要重启的设置显示为只读值，旁边的**复制**按钮可复制对应配置行。复制后，在 honk 主机上编辑文件的 `global` 段，再重启 honk。复制界面显示的重启命令不会执行该命令。字段说明见[需要重启的全局设置](what-doona-can-change.md#restart-global)和[配置参考](configuration.md)。


## 分享手动添加的节点 {#lite-task-share}

1. 打开**节点**，找到手动添加的节点。
2. 打开其**操作**菜单，选择**分享**。
3. 选择**复制链接**或扫描二维码。如果无法复制，可选中显示的链接手动复制。

此处不提供订阅节点的分享链接。链接过长而无法生成二维码时，复制链接即可。分享链接包含连接凭据，请仅发给预期的接收人。
