# Minimal configuration {#title-minimal-configuration}

Choose the configuration for the interface you want. For other options, see [Configuration](configuration.md).

| Interface | Configuration |
| --- | --- |
| Standard edition embedded in honk | [Quick start, step 2](quick-start.md#2-configure-honk) |
| doona lite embedded in honk | [Install doona lite](lite.md#lite-install) |
| Separately installed UI files | [Install doona separately](install.md) |

These blocks enable the UI and native API, not proxy routing. Keep your existing honk configuration or prepare the backend as described in [Quick start](quick-start.md).
