## 重新載入與暫停

設定變更後，可透過命令熱重新載入設定，不會中斷現有連線。需要暫停 dae 時，也可使用命令操作。

參見[重新載入與暫停](/zh-TW/dae/user-guide/reload-and-suspend)。
