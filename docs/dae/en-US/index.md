# Quick Start Guide

## Get started

1. [Check the kernel requirements](/dae/start/requirements): dae needs Linux 5.17 or later.
2. [Choose an installation method](/dae/installation/): a package, Docker or a manual build.
3. [Write a minimal configuration](/dae/start/minimal-configuration): add a subscription and routing rules.
4. [Start and verify the service](/dae/start/service-management#verify-the-service): enable dae and confirm it is running.

## Reload and Suspend

Reload the configuration without interrupting existing connections, or suspend dae temporarily.

See [Reload and suspend](/dae/user-guide/reload-and-suspend).

## Troubleshooting

See [Troubleshooting](/dae/troubleshooting).
