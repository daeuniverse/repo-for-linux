### Docker

预构建镜像及相关文档位于 <https://hub.docker.com/r/daeuniverse/dae>。

也可以使用 `docker compose`：

```shell
git clone --depth=1 https://github.com/daeuniverse/dae
cd dae
```

::: code-group

```shell [sudo]
sudo docker compose up -d --build
```

```shell [root]
docker compose up -d --build
```

:::
