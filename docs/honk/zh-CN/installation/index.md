# 安装 honk

从 Dae Universe APT/RPM 软件源安装 `honk`；Arch Linux 用户可选择 AUR 软件包。

软件包将 musl `full` 构建安装到 `/usr/bin/honk-core`，内嵌 doona 网页界面，并在 `/usr/share/honk/` 中创建指向 `/usr/share/v2ray-rules-dat/` 下 `geoip.dat` 和 `geosite.dat` 的符号链接。

- [Debian / Ubuntu](./debian.md)
- [Fedora / RHEL](./fedora.md)
- [openSUSE](./opensuse.md)
- [Arch Linux / Manjaro](./arch.md)
- [Docker](./docker.md)
- [OpenWrt](/zh-CN/openwrt/)

通过 APT/RPM 软件源安装软件包后，继续阅读[首次运行](./first-run.md)，配置并启动 honk。
