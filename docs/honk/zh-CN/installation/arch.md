# Arch Linux / Manjaro <Badge type="info" text="社区维护" />

使用 AUR 助手安装预编译的 [honk-core-bin](https://aur.archlinux.org/packages/honk-core-bin) 软件包。该包由社区维护，与本站的 APT/RPM 软件源无关。

## AUR

::: code-group

```shell [yay]
yay -S honk-core-bin
```

```shell [paru]
paru -S honk-core-bin
```

:::

安装后，参阅[如何开始](../how-to-start.md)完成配置并启动服务。
