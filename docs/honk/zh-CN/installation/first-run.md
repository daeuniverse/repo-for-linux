# 首次运行

在 [Debian / Ubuntu](./debian.md)、[Fedora / RHEL](./fedora.md) 或 [openSUSE](./opensuse.md) 上安装软件包后，按 honk 的[快速上手](../how-to-start.md)完成配置、启动服务和查看日志。

软件包安装带内嵌 doona 界面的 `full` 构建。在 honk 的[网页界面与 API](../how-to-start.md#网页界面与-api)中加入 `native_api` 块，再按 doona 的[首次登录](/zh-CN/doona/first-sign-in)打开界面。
