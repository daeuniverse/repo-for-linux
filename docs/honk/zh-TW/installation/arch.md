# Arch Linux / Manjaro <Badge type="info" text="社群維護" />

透過 AUR 助手安裝預先編譯的 [honk-core-bin](https://aur.archlinux.org/packages/honk-core-bin) 套件。此套件由社群維護，與本站的 APT/RPM 套件來源無關。

## AUR

::: code-group

```shell [yay]
yay -S honk-core-bin
```

```shell [paru]
paru -S honk-core-bin
```

:::

安裝完成後，請依[快速上手](../how-to-start.md)設定 honk 並啟動服務。
