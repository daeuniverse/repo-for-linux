# 首次執行

在 [Debian / Ubuntu](./debian.md)、[Fedora / RHEL](./fedora.md) 或 [openSUSE](./opensuse.md) 上安裝套件後，依 honk 的[快速上手](../how-to-start.md)完成設定、啟動服務和查看日誌。

套件安裝含內嵌 doona 介面的 `full` 建置版本。在 honk 的[網頁介面與 API](../how-to-start.md#網頁介面與-api)加入 `native_api` 區塊，再依 doona 的[首次登入](/zh-TW/doona/first-sign-in)開啟介面。
