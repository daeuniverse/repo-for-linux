# Arch Linux / Manjaro <Badge type="info" text="Community maintained" />

Install the prebuilt [honk-core-bin](https://aur.archlinux.org/packages/honk-core-bin) package from the AUR with an AUR helper. This package is community-maintained and independent of the APT/RPM repository.

## AUR

::: code-group

```shell [yay]
yay -S honk-core-bin
```

```shell [paru]
paru -S honk-core-bin
```

:::

After installation, see [How to start](../how-to-start.md) for configuration and service startup.
