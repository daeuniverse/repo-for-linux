# First run

Install the package from [Debian / Ubuntu](./debian.md), [Fedora / RHEL](./fedora.md) or [openSUSE](./opensuse.md), then follow honk's [Quick Start](../how-to-start.md) for the configuration, service startup and log commands.

The package installs the `full` build with the embedded doona UI. Add the `native_api` block from honk's [Web UI and APIs](../how-to-start.md#web-ui-and-apis), then open the interface as described in doona's [First sign-in](/doona/first-sign-in).
