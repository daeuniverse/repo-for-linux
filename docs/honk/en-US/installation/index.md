# Install honk

Install `honk` from the Dae Universe APT/RPM repository, or choose the AUR package for Arch Linux.

The package installs `/usr/bin/honk-core` from the musl `full` build, with the embedded doona web UI. It links `geoip.dat` and `geosite.dat` from `/usr/share/v2ray-rules-dat/` into `/usr/share/honk/`.

- [Debian / Ubuntu](./debian.md)
- [Fedora / RHEL](./fedora.md)
- [openSUSE](./opensuse.md)
- [Arch Linux / Manjaro](./arch.md)
- [Docker](./docker.md)
- [OpenWrt](/openwrt/)

After installing a package from the APT/RPM repository, continue with [First run](./first-run.md) to configure and start honk.
